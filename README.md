# Fibonacci Sequence in Python

A simple Python project that generates the Fibonacci sequence using basic Python programming concepts. This project is beginner-friendly and helps demonstrate mathematical logic and sequence generation.

## 🚀 Features

* Generates the Fibonacci sequence.
* Takes user input to determine the number of terms.
* Demonstrates basic Python programming concepts.
* Simple and easy-to-understand implementation.
* No external libraries required.

## 🛠️ Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <your-project-folder>
   ```

3. Ensure Python 3 is installed on your system.

## 📋 Requirements

* Python 3.x
* No external dependencies.

## 💻 Usage

Run the following command in your terminal:

```bash
python febonacci.py
```

Enter the number of terms when prompted to generate the Fibonacci sequence.

## 📌 Example

**Input:**

```text
Enter the number of terms: 7
```

**Output:**

```text
Fibonacci sequence:
0 1 1 2 3 5 8
```
